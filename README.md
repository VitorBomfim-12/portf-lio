# Portfólio Acadêmico — Vitor Bomfim Cunha

Portfólio acadêmico digital desenvolvido seguindo as orientações do curso de **Desenvolvimento de Software Multiplataforma (DSM)** da **FATEC São José dos Campos**, com identidade visual inspirada na estética tática de **Metal Gear Solid**.

## Estrutura do Projeto

- `index.html` — Estrutura semântica completa (Apresentação Pessoal, Projetos Acadêmicos API, Trajetória Profissional, Projeto Pessoal em Destaque, Currículo/Competências e Contato Codec)
- `styles.css` — Sistema visual tático (paleta obsidiana, off-white/bone e vermelho carmesim, retículos, divisores ink-brush e terminal Codec responsivo)
- `script.js` — Interações das abas de APIs, seletor de frequência do Codec, cópia rápida de e-mail, menu mobile e barra de progresso
- `assets/vitor-profile.jpg` — Foto pessoal profissional
- `assets/diamond-dogs.png` — Emblema Diamond Dogs em PNG transparente (usado como favicon, insígnia no HUD, patch no card de perfil, marca d'água no Codec e rodapé)

## Como Publicar no GitHub Pages

1. Crie um repositório público no seu GitHub (ex.: `portfolio` ou `VitorBomfim-12.github.io`).
2. Suba os arquivos `index.html`, `styles.css`, `script.js` e a pasta `assets/` (você pode ignorar o PDF e as imagens de referência no `.gitignore` se preferir).
3. No GitHub, acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**, escolha a branch `main` e a pasta `/ (root)`, e salve.
5. Em alguns instantes, o portfólio estará publicado online.

> **Dica do Guia FATEC (item 2.2.1):** recomenda-se manter um *fork* dos repositórios dos APIs (`FawkesCode/API-2026.02` e `FawkesCode/API-2026.01`) na sua conta pessoal (`VitorBomfim-12`) e atualizar os links no `index.html`, evitando quebra de link caso a organização ou algum colega altere/remova o repositório original.
